# Screenshot credits

The screenshots are native-resolution device captures using isolated, simulated
laundry entities. They include the surrounding screensaver, not fabricated UI.
The README displays them below their native 800-pixel width.

The Glass example includes a public nature photograph from
[Unsplash](https://images.unsplash.com/photo-1500534623283-312aade485b7).
That background remains under the [Unsplash license](https://unsplash.com/license),
not the source code's Apache license.
